# Hizkuntzen Didaktikako Ikuspegi Berriak

Biltegi honetan ikasgaiaren apunteak, diapositibak eta bestelako ikasgelako baliabideak daude.

- [Apunteen HTML bertsioa](apunteak-2026/index.html)
- [Apunteen PDF bertsioa](apunteak-2026/Hizkuntzen-Didaktikako-Ikuspegi-Berriak-V-0.6.pdf)

- [2026ko iturburu-fitxategiak](HDIB-2026/)

Apunteetan kapitulu bakoitzaren amaieran dagokion diapositibarako estekak daude, erabilgarri dagoenean. Irudiak eta bestelako baliabideak apunteen `assets/` eta `images/` karpetetan daude.

## Aurreko ikasturteak

Aurreko bertsioak [Zaharrak/](Zaharrak/) karpetan gordeta daude eta ez dira ezabatu. Bertan daude 2023ko eta 2024ko proiektuak, aurreko apunteak, liburu zaharra eta `Zain/` karpeta.

## Iturburuaren erabilera

2026ko apunteak Quarto bidez sortzen dira. Edukia aldatzeko, editatu `HDIB-2026/` karpetako `.qmd` fitxategiak eta berriz renderizatu dagokion formatua.
